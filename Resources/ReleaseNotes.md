# Optimal Layout 0.2.0

- A crisp window-grid menu-bar icon that adapts to light and dark appearance.
- Descriptive layout commands with their keyboard shortcuts shown in the menu.
- A warning symbol and accessible description when a window command or shortcut fails.
- Sparkle updates, with Check for Updates and an automatic-check preference in the menu.

Requires macOS 14 or later on Apple Silicon or Intel.
